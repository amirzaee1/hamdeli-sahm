# همدلی — سهم تو کجاست؟

صفحه‌ی لیدِ تعاملی با یک فیلم سینمایی ۸۰ ثانیه‌ای. برای کسانی ساخته شده که بیرون از این کار هستند: اول کنجکاو می‌شوند و آخر کار نام و شماره‌ی موبایلشان را برای یک گفت‌وگوی کوتاه ثبت می‌کنند.

## مسیر کاربر
1. **شروع:** پیش‌نمایش تارِ یک پیام از «سارا · ۲۳:۴۷» و دکمه‌ی «پیام رو باز کن ▶»
2. **فیلم، بخش ۱:** معما («یه چیزی هست که هر روز جلوی چشمته…») و پیام شبانه
3. **اسلایدر:** «تا حالا به چند نفر یه چیزی رو پیشنهاد دادی که بعدش خریدن؟». جواب با عدد خود کاربر برمی‌گردد.
4. **فیلم، بخش ۲:** کشف («تولیدکننده، فروشنده، دوستت… و تو؟»)
5. **نگه داشتن انگشت:** قبل از «سهم تو کجاست؟»
6. **فیلم، بخش ۳ و ۴:** جواب (اقتصاد مشارکتی) و حل معما. دکمه‌ی «بقیه‌ی ماجرا» از همین‌جا ظاهر می‌شود.
7. **دعوت، فرم** (نام، موبایل، رضایت) **و ثبت** با کد پیگیری

## ساختار
| مسیر | چیست |
|---|---|
| `index.html`، `styles.css`، `app.js` | خود سایت (برای GitHub Pages از ریشه سرو می‌شود) |
| `media/` | فیلم در ۴ تکه (`p1`–`p4`) و صداهای صفحه (`sl`، `cta`، `form`، `ok`) |
| `fonts/` | وزیرمتن (OFL) |
| `film/hamdeli-v2-film-80s.mp4` | کل فیلم ۸۰ ثانیه‌ای برای پیام‌رسان‌ها |
| `source/` | کد ساخت فیلم (Remotion) و ابزارهای صدا، برای مرجع |
